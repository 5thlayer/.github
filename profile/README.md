<h3 align="center">Fifth Layer Studio</h3>

<p align="center">

## FactoryWorks

Each mod owns one capability, plays in vanilla and mixes with any other tech mod.

### Mods

| | |
|---|---|
| [**Groundworks**](https://github.com/5thlayer/groundworks) | Library that draws Placement Plans: what a held item would place, translucent, red where refused. The only mod the others require. |
| [**Beltworks**](https://github.com/5thlayer/beltworks) | Factorio-style belts, laid block by block on the grid. Forked from Rearth's Simple Conveyor Belts. |
| [**Pipeworks**](https://github.com/5thlayer/pipeworks) | Pipes and tanks on Factorio 2.0's fluid model: a connected run is one segment holding one fluid, with no pressure. |
| [**Wireworks**](https://github.com/5thlayer/wireworks) | Electric poles: a pole powers every machine in its supply area, and wired poles share one FE network. |
| [**Craftworks**](https://github.com/5thlayer/craftworks) | Queued crafting plans: chain-crafts intermediates, reserves ingredients up front, refunds on cancel. |
| [**Fieldworks**](https://github.com/5thlayer/fieldworks) | Resources: ore patches that run down as you mine them, endless oil wells, and Harvesters to work them. |
| [**Voidworks**](https://github.com/5thlayer/voidworks) | Void Displacers turn blocks into motes and Voidstone, spent on Mutation and endgame gear. |
| [**Gearworks**](https://github.com/5thlayer/gearworks) | One FE-powered suit whose Gear Grid holds upgrades you level without a cap. |
| [**Railworks**](https://github.com/5thlayer/railworks) | Factorio's trains as a straddle-beam monorail. In design, not yet playable. |

The suite's glossary, cross-mod decisions and cross-mod issues live in [**factoryworks**](https://github.com/5thlayer/factoryworks).

### Modpack

[**FactoryWorks Showcase**](https://github.com/5thlayer/factoryworks-showcase): a CurseForge modpack that runs every mod of the suite together, alongside well-known tech mods. [Install it from CurseForge](https://www.curseforge.com/minecraft/modpacks/factoryworks-showcase).

## A Touch Of

Each mod brings one danger into an ordinary world and plays alone in vanilla; none requires another.

| | |
|---|---|
| [**A Touch of Darkness**](https://github.com/5thlayer/atouchofdarkness) | The Dark strikes anyone who stays unlit, and every light burns out. |
| [**A Touch of Madness**](https://github.com/5thlayer/atouchofmadness) | Sanity slips under pressure, and the shadows it lets in can kill. Not yet released. |
| [**A Touch of Wickedness**](https://github.com/5thlayer/atouchofwickedness) | Killing harmless creatures builds Wickedness, and too much of it brings the Bailiff to seize your goods. |

The suite's glossary, cross-mod decisions and the small runtime every mod nests live in [**atouchof**](https://github.com/5thlayer/atouchof).

## Tooling

| | |
|---|---|
| [**libworks**](https://github.com/5thlayer/libworks) | The shared base of every mod: the Gradle convention plugin and CI they build with, the runtime mod they nest, and the template a new one starts from. |
| [**skillworks**](https://github.com/5thlayer/skillworks) | Claude Code skills for working on the 5thlayer mods. |
| [**hytale-mod-template**](https://github.com/5thlayer/hytale-mod-template) | A release-ready Hytale mod template: renames itself on first push, and releases from a tag to GitHub, CurseForge, Modtale and Modifold. |
