<h3 align="center">Factorio-style automation for Minecraft</h3>

<p align="center">
  NeoForge mods and modpacks: belts laid block by block, queued crafting plans, and placement previews,<br>
  each built as a small library that works alongside any tech mod.

### Mods

| | |
|---|---|
| [**Beltworks**](https://github.com/5thlayer/beltworks) | Factorio-style conveyor belts, laid block by block on the grid. Forked from Rearth's Simple Conveyor Belts. |
| [**Craftworks**](https://github.com/5thlayer/craftworks) | Queued crafting plans: chain-crafts intermediates, reserves ingredients up front, refunds on cancel. |
| [**Groundworks**](https://github.com/5thlayer/groundworks) | Library that draws Placement Plans: a translucent preview of what the held item would place, red where refused. |

### Modpack

**PlanetaryFactory**: a Factorio-inspired NeoForge pack built on the mods above. In development, not public yet.

### Tooling

| | |
|---|---|
| [**libworks**](https://github.com/5thlayer/libworks) | Template every 5thlayer library starts from: build, GameTest harness, release scripts, REUSE, agent docs. |
| [**skillworks**](https://github.com/5thlayer/skillworks) | Claude Code skills for working on the 5thlayer mods. |
